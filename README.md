\# LSTM Stock Price Prediction



This project predicts stock closing prices using an LSTM (Long Short-Term Memory) neural network.



The goal of this project is to demonstrate:

\- Time series forecasting with deep learning

\- Clean, modular machine learning project structure

\- Real-world financial data processing



\## Tech Stack

\- Python

\- TensorFlow / Keras

\- Pandas, NumPy

\- Scikit-learn

\- yFinance

\- Matplotlib
